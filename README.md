# 残響カセット

PCで鳴っている音（Spotify、YouTube、ゲームなど）を、カセットテープや深夜のAMラジオのような「少し遠い記憶の音」に変えて聞くための、ブラウザで動くツールです。インストールは不要で、ページを開くだけで使えます。

```
アプリの音 → CABLE Input →（VB-CABLE）→ CABLE Output → 残響カセット → ヘッドホン／スピーカー
```

---

## ⚠️ はじめに必ず読んでください

- **音量に注意してください。** 最初はヘッドホンやスピーカーの音量を小さめにしてから再生してください。プリセットやつまみの組み合わせによっては、急に大きな音やノイズが出ることがあります。耳を傷めないよう、ご自身で調整してください。
- **残響カセットを閉じると、PCの音が一切聞こえなくなります。** Windowsの出力先を「CABLE Input」にしたままだからです。ふつうの音に戻すときは、Windowsの「設定 → システム → サウンド → 出力」をいつものスピーカー／ヘッドホンに戻してください。
- **少しだけ音が遅れます**（0.05〜0.1秒ほど）。動画では口の動きとわずかにずれます。音ゲーなど、タイミングが大事な用途には向きません。
- **マイクの許可を求められます。** PCの音は、ブラウザからは「マイク」として受け取るためです。音はブラウザの中だけで処理され、どこにも送信・録音されません。
- 動作環境は **Windows 10/11 + Google Chrome（最新版）** です。ほかのブラウザやOSでは、出力先の切り替えができないなどの理由で動かないことがあります。
- 本ツールは無保証です。使用によって生じたいかなる損害についても、作者は責任を負いません（詳しくは [LICENSE](LICENSE) を見てください）。

## 事前準備（最初の一回だけ）

1. VB-AUDIO 公式サイトから **VB-CABLE Driver** をダウンロードします。
   - 残響カセットにはドライバーを同梱していません。必ず公式サイトから入手してください。
   - VB-CABLE は寄付制（ドネーションウェア）のソフトです。気に入ったら作者を支援してください。
2. `VBCABLE_Setup_x64.exe` を右クリック →「管理者として実行」でインストールします。
3. PCを再起動します。
4. 「設定 → システム → サウンド → 出力」で **CABLE Input** を選びます（この時点でPCの音は聞こえなくなりますが、正常です）。
5. 「サウンドの詳細設定」で、CABLE Input と CABLE Output のサンプリングレートを両方 **48000 Hz** にそろえます。

## 使い方

1. Chrome で残響カセットのページを開きます。
2. 「マイクの使用」を聞かれたら **許可** します。
3. 入力には「CABLE Output」が自動で選ばれます。出力にはヘッドホン／スピーカーが自動で選ばれるので、違っていたら「接続設定」で変えてください。
4. 音楽や動画を再生すると、劣化した音が聞こえます。

| 操作 | キー |
| --- | --- |
| エフェクト ON/OFF | `Space` |
| 押している間だけ原音 | `B`（または「押して原音と比較」ボタン） |
| プリセット切り替え | `1`〜`8` |

- **マイプリセット**：今のつまみに名前をつけて保存できます（同じ名前なら上書き）。
- **音量を原音にそろえる**：エフェクトをかけても、原音とだいたい同じ音量になるよう自動で調整します。
- デバイス・つまみ・プリセット・音量は自動で保存され、次に開いたときに復元されます。
- 「ファイル」タブでは、手元の曲（mp3 / wav / flac など）をドラッグ＆ドロップで再生できます。ファイルはブラウザの中だけで再生され、アップロードはされません。

### 小さなウィンドウで常駐させたいとき

Chrome のメニュー（︙）→「キャスト、保存、共有」→「ページをアプリとしてインストール」を選ぶと、アドレスバーのない独立したウィンドウで開けます。幅420px程度まで縮めても使えるので、画面の端に置いておけます。

## 困ったとき

- **「5秒以上、音が届いていません」と出る**
  - Windowsの出力先が CABLE Input になっているか確認してください。
  - 「設定 → サウンド → 音量ミキサー」で、アプリごとに出力先が個別に指定されていないか確認してください。「既定」か「CABLE Input」なら大丈夫です。
- **「CABLE Output が見つかりません」と出る**：VB-CABLE をインストールしたあと再起動したか確認し、「デバイスを再検索」を押してください。
- **マイクを「ブロック」してしまった**：アドレスバー左の鍵（または調整）アイコン →「マイク」を「許可」にして、ページを再読み込みしてください。アプリとしてインストールした場合は、ウィンドウ右上の「︙」→「アプリ情報」から変更できます。
- **ハウリングしそう**：出力先に CABLE 系のデバイスは選べないようにしてあります。ヘッドホンを抜いたときは自動で別の出力に切り替わり、つなぎ直すと元に戻ります。
- **原因がわからない**：「接続設定」を開くと、一番下に診断情報（入力の状態や音量）が出ます。問い合わせのときはこの内容を添えてください。
